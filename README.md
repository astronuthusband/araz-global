## About

This project is the official website developed for **Araz Global**, designed to establish a professional online presence and clearly communicate the company's services, capabilities, and brand identity.

The website focuses on a clean, modern interface with responsive layouts that provide a consistent experience across desktop, tablet, and mobile devices.

## Project Highlights

* Modern corporate website design
* Fully responsive across devices
* Clean and professional UI
* Brand-focused visual design
* Optimized page structure and navigation
* Mobile-friendly layouts
* Clear presentation of company services
* Contact and enquiry functionality

## Tech Stack

* **HTML5**
* **CSS3**
* **JavaScript**
* **Responsive Web Design**
* **Git & GitHub**

## Design

The design was created around Araz Global's existing brand identity, using a professional visual direction with emphasis on:

## Development

The website was designed and developed with a focus on performance, usability, and maintainability.

The frontend uses a lightweight structure to ensure fast loading times while maintaining a polished visual experience.

## Responsive Design

The website is optimized for:

* Desktop
* Laptop
* Tablet
* Mobile

Each section adapts to different screen sizes while maintaining the intended visual hierarchy and user experience.
